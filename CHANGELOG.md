# Changelog

## 0.1.2rc15 — experimental source preview, 3 November 2026

This preview packages development snapshot `90b9c59` with documentation written for public evaluation. It does not introduce a new program version or change the program and tests.

The development snapshot includes repairs to capture-gap reporting, recovery retention, file-change detection, policy validation, excluded-file reporting, hook-file recovery and lease checks. Those repairs still need independent review and Windows validation. They do not establish complete recovery or guard coverage.

The public documentation now provides a disposable demo, a task-oriented guide, troubleshooting and a consolidated limitations page. The validation summary distinguishes recorded development results from checks performed on the archive. It also identifies two unchanged tests that depend on the original internal documentation layout.

This is not a stable release. See [validation status](ACCEPTANCE.md), [known limitations](docs/limitations.md) and [source identity](SOURCE-IDENTITY.json).
